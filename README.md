# Yash Bankhele Portfolio

Responsive portfolio website built with plain HTML, CSS, and JavaScript. It has no build step or package dependencies.

## Run locally

Open `index.html` in a browser, use VS Code Live Server, or run:

```powershell
py -m http.server 8000
```

Then visit <http://localhost:8000>.

## Deploy to GitHub Pages

This repository is named `YashBankhele.github.io`, so GitHub Pages can serve the site at <https://yashbankhele.github.io/>.

In the repository settings, open **Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, and save. The site's `index.html` is already at the repository root.

## Assets

- Profile photo: `assets/photo.jpg`
- Resume placeholder: `assets/resume/Yash-Bankhele-Resume.pdf`

Only add a resume PDF if you are comfortable making it publicly accessible. Update the Resume section in `index.html` when the PDF is ready.
